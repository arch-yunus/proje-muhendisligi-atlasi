# ProjectLibre Kılavuzu

ProjectLibre, masaüstü proje yönetiminde MS Project'in en güçlü açık kaynaklı alternatifidir. Bu klasör, ProjectLibre kullanımına ilişkin derinlemesine rehberler, şablonlar ve pratik örnekler içerir.

## 📁 Klasör Yapısı

- **rehberler/** - Kullanım kılavuzları ve öğretici dökümantasyon
- **sablonlar/** - `.mpp` ve `.pod` dosya şablonları
- **ornekler/** - Gerçek dünya proje örnekleri
- **kisayollar.md** - Klavye kısayolları ve üretkenlik ipuçları

## 🎯 Hızlı Başlangıç

### Temel Kavramlar

1. **İş Kırılım Yapısı (WBS):** Projeyi yönetilebilir bileşenlere ayırma
2. **Gantt Şeması:** Görev zaman çizelgesinin görselleştirilmesi
3. **Kritik Yol (CPM):** Projenin toplam süresini belirleyen görevler
4. **Kaynak Optimizasyonu:** Kaynakların etkili yönetimi

### İlk Proje Adımları

1. Görevleri tanımlayın ve WBS oluşturun
2. Bağımlılıkları belirleyin
3. Kaynakları atayın
4. Temel Çizgi (Baseline) alın
