# Leantime Kılavuzu

Leantime, başlangıçtan ürüne kadar olan tüm süreci yöneten açık kaynaklı bir ürün yönetim platformudur. Stratejik planlama ile operasyonel görev yönetimini birleştirir.

## 🎯 Ana Özellikler

- **Strateji Planlama:** Amaçlar (OKR), KPI ve yol haritası
- **İdea Yönetimi:** Konsept aşamasından ürüne kadar
- **Sprint Yönetimi:** Agile iş akışları
- **Portföy Görünümü:** Birden fazla projeyi izleme

## 👥 İdeal Kullanım Senaryoları

- Girişimler ve startuplar
- Ürün yönetimi
- Stratejik planlama ve KPI takibi
- Proje portföyo yönetimi

Leantime, Asana, Monday.com gibi araçlara açık kaynaklı, uygun maliyetli bir alternatif sunar.

## 🏗️ Mimarisi

- PHP ve Vue.js tabanlı
- PostgreSQL/MySQL desteği
- Self-hosted seçeneği
- REST API
