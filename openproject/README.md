# OpenProject Kılavuzu

OpenProject, çevik yazılım geliştirme ekipleri için ideal açık kaynaklı proje yönetim platformudur. Scrum, Kanban ve Waterfall metodolojilerini destekler.

## 🎯 Ana Özellikler

- **Agile/Scrum Panoları:** Sprint yönetimi ve kart tabanlı görev takibi
- **Entegre Wiki:** Proje dokümantasyonu ve bilgi havuzu
- **Yol Haritası Yönetimi:** Ürün geliştirme rotasının planlanması
- **Çeşitli Görünümler:** Kanban, Gantt, Tablo ve Takvim görünümleri

## 📊 Yazılım Geliştirme İçin Uygunluk

OpenProject, özellikle:
- Yazılım geliştirme ekipleri
- Sprint tabanlı iş yönetimi
- Bug ve issue takibi
- Ürün backlog yönetimi

gibi senaryolarda Jira'ya güçlü bir alternatif sunar.

## 🔧 Kurulum ve Konfigürasyon

- Docker ile kolay kurulum
- PostgreSQL veritabanı desteği
- Multitenancy desteği
- API aracılığıyla entegrasyon
